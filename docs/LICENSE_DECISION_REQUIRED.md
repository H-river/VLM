# License decision required

No license was present at the start of this cleanup, and repository ownership,
third-party code provenance, dataset redistribution rights, simulator asset
rights, and model/checkpoint terms are not sufficiently documented to select
one safely.

Before making the repository public, a responsible owner should:

1. identify every copyright holder and institutional policy that applies;
2. review third-party source and generated assets under `legacy/` and active
   packages;
3. document dataset and model licenses, including Qwen base-model and adapter
   distribution terms;
4. decide whether generated simulator data can be redistributed;
5. choose a source license and, if needed, separate data/model terms; and
6. add `LICENSE` only after those decisions are approved.

Until then, the repository is appropriate only for private review. Absence of a
license is not permission to copy, modify, or redistribute the work.
