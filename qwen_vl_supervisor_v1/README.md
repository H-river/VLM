# Qwen-VL Supervisor v1

This contained module prepares a Qwen2.5-VL high-level optics supervisor without modifying the frozen forward model, anomaly generators, measurement specialists, CEM controller, or continuation rule.

The source flow is:

```text
frozen source JSONL + images
  -> versioned strict manifests
  -> deterministic Qwen chat JSONL
  -> development-only QLoRA smoke / future server SFT
  -> strict offline parser and guarded frozen-controller adapter
```

The manifest is authoritative. Chat JSONL is derived and may be regenerated byte-identically with the same seed. The model emits only diagnosis, measurement policy, and high-level action enums; continuous controls are always produced by frozen H1 one-step CEM.
